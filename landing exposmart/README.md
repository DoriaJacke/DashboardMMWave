# Landing ExpoSmart 2026 — Aeris MedRadar

Sitio de presentación del proyecto para la **ExpoSmart 2026**
(miércoles 02 de diciembre, 08:30 h, Auditorio Rojo).

- URL pública: https://aeris.exposmart.cl
- Publicación: subir el **contenido** de esta carpeta (no la carpeta en sí) por FTP/SFTP
  con FileZilla o Bitvise. `index.html` debe quedar en la raíz del subdominio.
- Las credenciales FTP **no se guardan en el repositorio**; están en el correo de la organización.

## Estructura

```
landing exposmart/
├── index.html      Página única con todas las secciones
├── css/styles.css  Estilos
├── js/main.js      Menú móvil y animaciones
└── img/            Logo, banner, mockups y capturas del dashboard
```

## Checklist de contenido mínimo (requerido)

- [ ] Identidad visual: logotipo y banner del proyecto (logo pendiente, se diseña después)
- [ ] Descripción: problemática y solución propuesta
- [ ] Objetivo general y objetivos específicos
- [ ] Características: funcionalidades principales y tecnologías usadas
- [ ] Imágenes: mockups / capturas del dashboard y del hardware
- [ ] Integrantes: nombres del equipo
- [ ] Información adicional: innovación, impacto, resultados del piloto
